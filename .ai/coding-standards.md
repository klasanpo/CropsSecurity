# Padrões de código para o Codex

- Python 3.12+, tipos explícitos, Ruff e Pytest.
- React funcional, TypeScript estrito, ESLint e Vitest.
- APIs versionadas em `/api/v1` e contratos testados.
- Configuração por ambiente; nunca registre segredos.
- Toda correção de bug recebe teste de regressão.
- Valide backend, frontend e Compose antes de concluir.
