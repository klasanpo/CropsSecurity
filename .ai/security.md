# Regras de segurança para o Codex

- O projeto destina-se somente a testes autorizados.
- Não inclua alvos reais, credenciais, tokens, dados de cliente ou evidências.
- Novos scanners devem validar escopo, ter limites conservadores, cancelamento e auditoria.
- Mudanças no core exigem testes unitários e de regressão dos consumidores.
